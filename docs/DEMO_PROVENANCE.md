# 演示数据与结果的来源

`examples/historical_bars.json` 只包含平安银行（000001）在 2026-08-28、2026-08-31、2026-09-01 的三条未复权 OHLC 市场记录，以及各原始行的 SHA256。来源是项目保存的 BaoStock 0.9.4 历史采集；取 `raw_open/raw_high/raw_low/raw_close`，没有使用前复权价格充当可执行现价。

样本不包含账户、个人持仓、成交历史、新闻正文或凭证。数据用于复现规则的极小事实样本，不代表训练集或数据完整性已公开验证。接口文档见 [BaoStock](https://www.baostock.com/)。

回放情景由项目预设：虚拟初始资金 100,000 元，第二条行情按收盘价代理计算一笔预算 20,000 元的假设买单；同日卖出被 T+1 拦截；第三条行情按收盘价代理计算假设退出。滑点、佣金及印花税来自项目当前费用实现。

回放不是原账户发生过的交易，也不是扫描器选股结果。日线收盘价代理无法证明盘中成交机会和流动性；这一个情景的净盈亏不用于评价策略收益。每次运行会重新调用代码、生成临时记录并核对账户现金，不分发缓存好的“成功结果”。

生成时间与历史交易时点分开：此场景显式使用历史回放时钟；正式撮合默认实际时钟，正式赛季安全检查保持原样。样本文件哈希会随回放 JSON 一并返回，便于核对输入版本。


## 界面示例与历史回放分开

上述真实历史样本只用于`/replay`和`/api/demo`的假设撮合回放。默认`/demo`现使用新版工作台与合成展示数据，见[界面说明](UI_PREVIEW.md)；两者不共用行情或账户结果。
