# 界面与公开预览

## 组件范围

当前公开预览使用 v3-r3 工作台：18 个页面共享导航、字体、图标、表格、详情、状态和布局组件。首页呈现市场环境、策略观点、候选、账户与新闻摘要。

预览直接读取 `workbench_v7/index.html` 及其资源，不维护另一套静态截图页面。README 图片由同一公开入口生成。

## 入口与数据

| 页面 | 接口 | 数据性质 |
|---|---|---|
| `/demo` | `/api/ui-demo/*` | 手写文本、合成曲线、场景观点和示意账户指标 |
| `/v7` | `/api/v7/*` | 聚合实际可用的公开输入；缺失生产数据保持不可用 |
| `/replay` | `/api/demo` | 三条历史价格上的假设订单与规则回放 |

`scripts/public_ui_fixture.py` 为合成接口提供数据，不读取生产账户、新闻库、数据库或凭证，不调用行情源、LLM、模型或交易流程。响应带 `demo.synthetic=true` 和 `execution_authorized=false`。

合成日期取显示时钟以适配组件，不表示真实交易日、采集时间或数据资格。账户数值不是成交计算结果；分数与概率不是模型推理结果。候选名称与数字代码仅作格式示例，不作为研究推荐。

## 表达约束

- 页面持续标明“界面示例 · 合成数据”。
- 没有实际报价和来源证据的候选保持待确认状态，不为着色构造行情资格。
- 合成观点和新闻正文只服务组件阅读，不冒充采集信息。
- 合成接口不生成正式成交、不写账户账本、不累计 Forward 天数。

README 三张截图来自此入口。截图和源组件保持一致，均不包含私人工作台内容；图片字节由发布检查按 SHA256 固定。[截图检查](PRIVACY.md#reviewed-ui-screenshots)

历史回放的市场来源和代理限制见[样本说明](DEMO_PROVENANCE.md)。
