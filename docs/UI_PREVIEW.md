# 最新界面示例

当前默认示例使用 **v3-r3** 界面：18个页面共享浅色外壳、字体、细线图标、表格、详情与状态组件。首页包含市场走势、五策略观点、等面积候选股票格、账户条形与新闻；包括竖线伸展、风险卡片底部对齐、新闻技术提示清理及选股卡片基线对齐这轮调整。

启动 `python -m scripts.public_preview` 后：

- `/demo`：最新版交互界面，顶部持续显示“界面示例 · 合成数据”。
- `/v7`：同一版界面的无数据状态；没有分发的私有数据保持不可用。
- `/replay`：三条真实历史行情上的假设撮合回放；`/api/demo`仍运行原费用、T+1与对账逻辑。

界面示例直接读取仓库中的 `workbench_v7/index.html` 和组件资源，没有另一份会逐渐过期的截图网页。公开预览禁止写API、不启动调度或连接行情/LLM。

## 合成数据的范围

`scripts/public_ui_fixture.py`只为`/api/ui-demo/*`生成手写文本、合成曲线、场景观点和示意账户指标。与`/api/v7/*`分离，不读取生产账户、新闻库、数据库或凭证。日期取当前显示时钟以满足组件日期校验，不代表真实交易日、采集时点或数据准入。所有响应携带`demo.synthetic=true`与`execution_authorized=false`；组件里的资格字段仅用于示例渲染，不证明真实市场证据。

示意账户数值不是从成交计算的账本或策略绩效，示例不构造成交、不累计Forward天数。候选股票使用“示例资源”等虚构名称；六位数字代码仅是格式示例，不对应选股建议。没有实际报价及行情源证据，因此候选涨跌保持灰色“待确认”，不伪造数据源标识为候选着色。模型候选的分数和概率也只是组件示意，不是运行模型的结果。
