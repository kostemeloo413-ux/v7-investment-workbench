# 界面与公开预览

知策使用原生工作台组件展示市场研究、账户与博主实验室。预览直接读取 `workbench_v7/index.html` 及资源，README 截图由同一入口生成。

## 入口与数据

| 页面 | 接口 | 数据性质 |
|---|---|---|
| `/demo` | `/api/ui-demo/*` | 手写新闻、合成走势、候选和账户指标 |
| `/demo#page-blogger-lab` | `/api/ui-demo/blogger-lab/*` | 虚构分身、资料、知识、规则、候选与成交样例 |
| `/v7` | `/api/v7/*` | 聚合实际可用输入；生产数据缺失时保持不可用 |
| `/v7#page-blogger-lab` | `/api/blogger-lab/*` | 显式启用后操作独立实验数据；默认关闭 |
| `/replay` | `/api/demo` | 三条历史价格上的假设订单与规则回放 |

`scripts/public_ui_fixture.py` 与 `scripts/public_lab_fixture.py` 提供合成数据，不读取生产账户、新闻库、数据库或凭证，不调用模型、行情源或交易流程。响应携带 `demo.synthetic=true` 和 `execution_authorized=false`。

工作台合成日期用于适配展示时钟，不代表真实行情资格。实验室样例固定在历史日期，知识与成交均为手写数据，不是模型抽取、扫描或撮合的实际结果；原文切片来自内置虚构短文。

## 可以操作什么

默认示例可以浏览页面、展开详情、切换实验室五步并查看原文切片。实验室注册、上传、提炼、规则确认、扫描、回放等写操作禁用；刷新仅重新读取样例。未知示例资源返回不可用，不回退到真实 API。

真实实验室启用方式见 [运行指南](BLOGGER_LAB.md#运行自己的实验)。启用后 `/demo` 仍保持只读合成数据，自己的资料在 `/v7#page-blogger-lab` 操作。

## 截图与结果边界

- 示例页面持续显示“界面示例 · 合成数据”；实验室另标注手写样例与非模型输出。
- 展示角色使用化名或虚构名称，不含生产账户、私人新闻或第三方原始语料。
- 示例不产生正式成交、不写账户账本、不累计 Forward 天数；合成分数与账户数值不能评价策略。
- README 的总览、新闻、候选及四张实验室截图来自上述入口，均经过视觉审阅并按 SHA256 固定。[截图检查](PRIVACY.md#reviewed-ui-screenshots)

历史回放的实际市场来源与代理限制见 [样本说明](DEMO_PROVENANCE.md)。
