## 术语

| 术语 | 含义 |
|---|---|
| 观点 | 对新闻或事件的解释，不能直接证明可执行性 |
| 策略信号 | 在指定规则和证据条件下形成的判断 |
| 执行资格 | 满足数据、账户、赛季、时段与交易约束的条件 |
| 订单 / 成交 | 交易意图 / 按撮合规则形成的记录，分别保存 |
| HOLD / NO_SIGNAL | 当前动作受限 / 当前未形成有效策略信号 |
| stale | 数据已超过相应消费场景的有效时限 |
| Forward | 模型与规则冻结后按实际时间推进的观察；合格天数由证据门确认 |
