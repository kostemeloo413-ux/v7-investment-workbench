# 交易链路恢复

历史行情停止更新时，原 AI Quant 周期会在检查持仓退出之前失败。修复后的顺序是：**当前报价与账本安全 → 持仓退出与估值 → 历史数据、模型与新开仓**。历史输入过期或损坏仍会阻断买入；有效报价下的退出检查可以继续执行。

持仓天数按正式交易日历计算，排除休市日。无有效报价、T+1、停牌、跌停和账本不安全等执行约束继续生效。重复周期保持卖出幂等。

日终恢复逐交易日推进：保存独立采集证据，验证日期有效股票池和完整性，经授权写入行情库，再滚动并校验 AIQ 复权窗口，最后原子发布缓存指针。失败保留上一合格版本和原始 HOLD；启动时检查缺口，17:30、19:30 有限重试。实际协议请求跨运行累计，不能通过重启清空预算。

三项已核实的退市生效证据，解决旧资格逻辑在摘牌当天仍要求报价的问题。只对匹配证券、日期和原始身份的缺失状态进行排除；其他缺失证据继续 HOLD。来源为[信达证券上交所公告](https://www.sse.com.cn/disclosure/announcement/listing/stock/c/c_20261012_10834561.shtml)、[东兴证券上交所公告](https://www.sse.com.cn/disclosure/announcement/listing/stock/c/c_20261012_10834560.shtml)、[康佳公司披露公告](https://static.cninfo.com.cn/finalpage/2026-10-23/1225615607.PDF)。冻结的 V2/G6 核心未改动；公开副本单独绑定已脱敏源码的字节哈希。
